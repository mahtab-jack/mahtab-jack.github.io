# mahtab-jack.github.io

Personal portfolio website for **Mahtab Jack** -- built with a retro 90s / Windows 95 design theme.

## Live Site

[https://mahtab-jack.github.io](https://mahtab-jack.github.io)

## Features

- Retro Windows 95/98 aesthetic with beveled panels, title bars, and classic system fonts
- Rainbow animated text and marquee scrolling banner
- Live GitHub profile stats (repos, followers, following) with animated counters
- Dynamic project cards loaded from the GitHub API
- Skills/toolbox section with colorful retro tiles
- Contact section with links to GitHub, Twitter/X, Blog, and Email
- Guestbook form for visitor messages
- Construction stripe CTA section
- Fully responsive -- works on mobile, tablet, and desktop
- Scroll-reveal animations
- Accessibility-friendly with reduced motion support

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks, no build tools)
- GitHub Pages for hosting
- GitHub REST API for live data
